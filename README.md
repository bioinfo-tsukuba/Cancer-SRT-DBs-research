# README
This is a GitHub repository for our article `The landscape of human cancer data in spatial transcriptomics databases highlights challenges in metadata curation and integration`.

This repository has two main projects:

- **Analysis**: Analysis for collecting data. 
Contains scripts, input files, and documentation used for analyzing human cancer–related metadata from spatial transcriptomics (SRT) databases. Each subproject folder includes its own README with detailed usage.

- **Data_collection**: Data collection part for our study.
Contains scripts and materials used in the data collection and curation process prior to analysis.

For details on each part, please refer to the corresponding README files inside the subdirectories.
