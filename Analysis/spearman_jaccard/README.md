# README

## Overview
This folder contains a Python script for correlation analysis between **Jaccard similarities based on overall GSM sets (Jaccard (overall GSM sets))**, **Jaccard similarities based on GSM error carriers (Jaccard (GSM carriers))**, and **shared GSM error counts**. 
Input file for this script is also contained.

### 2. spearman_jaccard.py
This script calculates `Spearman's rho values and corresponding p-values` between following variables in `input.xlsx`:  
**jaccard_overall_gsm**: Jaccard similarities based on overall GSM set structures.
**jaccard_carry**: Jaccard similarities based on GSM error carrier structures. 
**shared_gsm_error**: Counts of shared GSM errors between the databases. 

These variables in the input file can be created by `make_network.py` in `network` project.
Finally, this script outputs scatter plots for results visualization.

> *Note*
> Although `jaccard_overall_gsm` and `shared_gsm_error` have no empty cells, 
> some cells in `jaccard_carry` are empty. 
> Therefore, this script drops these empty cells in `jaccard_carry` from the analysis.

#### Input file
Unlike the scripts in `../network`, this analysis **does not require** `chccsrtdb_analysis.xlsx`.  
Instead, the following files and columns are required:

**File**: `input.xlsx`
**Columns**: `jaccard_overall_gsm`, `jaccard_carry`, `shared_gsm_error`

This file was created from following two CSV files generated by `make_network.py` in `network` project. 
**db_db_error_edge_metrics.csv**: Includes `jaccard` and `shared_gsm_error` columns. `jaccard` is used as `jaccard_overall_gsm` in the `input.xlsx`.  
**db_db_carry_edge_metrics.csv**: Includes `jaccard_carry`.

> *Note*
> The input file name is hardcoded in this script. 
> Therefore, don't change the input file name from `input.xlsx`.  


#### Usage example
```bash
# Run in VS Code terminal, with both spearman_jaccard.py and input.xlsx in the same folder
python3 spearman_jaccard.py

```

#### Outputs
The script makes `jaccard_correlation_results/` folder, and generates the following seven files under this new folder:

| Output file | Description |
|--------------|-------------|
| **scatter_jaccard_overall_gsm.png/svg** | The scatter plot for the correlation between `jaccard_overall_gsm` and `shared_gsm_error`. Spearman's rho value, p-value, and the number of data points are indicated. |
| **scatter_jaccard_carry.png/svg** | The scatter plot for the correlation between `jaccard_carry` and `shared_gsm_error`. Spearman's rho value, p-value, and the number of data points are indicated. |
| **scatter_overall_vs_carry.png/svg** | The scatter plot for the correlation between `jaccard_overall_gsm` and `jaccard_carry`. Spearman's rho value, p-value, and the number of data points are indicated. |
| **spearman_correlation_summary.csv** | CSV file contains each Spearman's rho (`spearman_r`), p-value (`p_value`), and the number of data points (`n`). |
